# Model 1 生成器评估：完整结果与指标分级

日期：2026-11-21。评估对象：E5（当前模型），M3 block bootstrap knob。依据：离网 PtM 设计 + 调度 MILP 的下游实验。指标名称沿用 `evaluation-metrics-summary.md`。只看结论请读 [`scenario_eval_metrics.md`](scenario_eval_metrics.md)。

## 结论（先读）

1. **重点关注两项，E5 在这两项上有偏差，而且会改变设计：**
   - **逐日平均风速的标准差**：E5 偏低 3.9%，储氢罐因此小约 530 kg，按真实天气运行每年多缺货约 23 t。
   - **静风小时数（风电 CF < 0.05，即 v < 4.47 m/s）**：E5 偏少 8%。
2. **守住四项**：平均风速（knob 跟踪）、光伏总量、日尺度风光相关、逐日光伏波动。设计对它们很敏感，以光伏为主时尤其如此；E5 目前没有偏差，只要求不变差。
3. **小时尺度的纹理指标维持现状即可。** 你改模型时常看的 \|dv\| 分位数、kurt、win_dvstd_cv，以及 sign_keep、acf_absdv_3 等都属于这一类。把 E5 的小时纹理整体换进真实天气后，设计成本、储氢罐、遗憾和固定设计下的调度成本都没有显著变化，只有电池容量小 0.3 MWh。
4. **对这个下游可以不看：** wind_max 和其他额定风速以上的指标，以及风速日变幅。
5. **判定方式要改：** 第 1、2 类指标应看与真实天气类比年配对后的偏差及其置信区间，不能只看是否落在真实逐年 p10–p90 范围内。E5 的逐日风速标准差平均值落在真实范围内，按现行规则算"达标"，但它正是造成储氢罐偏小的主因。

## 1. 评估方法

**下游模型**：Kassø 站点的离网 PtM 系统，包括风电、光伏、PEM 电解槽（2.5 MW 一个模块）、电池、储氢罐和甲醇合成。
- 甲醇装置全年不停机，负荷在铭牌产能（κ × 1000 kg/h）的 20–100% 之间，爬坡限制为每小时 50%。
- 缺电罚金 2000 USD/MWh，甲醇缺货罚金 5000 USD/t。
- 先在一条天气序列上优化容量（设计），再把容量固定，在真实 2024–25 天气上运行，得到实际成本。

**遗憾**：在序列 X 上做的设计，在真实 2024–25 天气上的成本，减去直接用真实天气做的最优设计的成本，再除以后者。遗憾几乎全部来自缺货罚金，而且不对称：储能配小的代价远大于配大。

**参照系**：同一套 knob 序列构造的**真实天气类比年**。对每个 12 天片段，从 2005–2023 年（不含 2021）的历史中挑一段 24 天平均风速最接近、季节相差 ±30 天以内的真实窗口，拼成一整年。比较对象是"同样条件下的真实天气"，而不是零误差。

**四组实验：**

| 实验 | 内容 | 回答的问题 |
|---|---|---|
| 整体遗憾 | 50 个 E5 场景 vs 50 个独立类比，四种系统配置 + 50 个合成年 | E5 整体是否像真实天气 |
| 观测筛选 | 68 个真实天气年份，回归设计结果对各统计量 | 哪些统计量可能有影响 |
| 单指标扰动 | 在 25 个真实类比年上只改一个统计量（保持年均风电和光伏 CF 不变），与改之前配对比较 | 因果敏感度，以及 E5 的偏差值多少钱 |
| 小时纹理替换 | 保留真实年份的日尺度风速，把小时残差换成 E5 的，对照组换成另一条真实类比年的残差；再做固定设计下的调度检验 | 小时纹理整体是否重要 |

## 2. 整体结果：E5 vs 真实天气类比

| 配置 | 真实最优成本 USD/t | 单设计遗憾 E5 / 类比（p） | 50 个共识设计 E5 / 类比 | 储氢罐 E5 / 类比 / 真实最优（t） |
|---|---|---|---|---|
| κ = 1.0 | 1193.1 | 1.98 / 2.15%（0.32） | 0.67 / 1.52% | 17.1 / 20.0 / 16.8 |
| κ = 1.25 | 951.0 | 3.66 / 3.48%（0.96） | 0.60 / 0.60% | 7.77 / 8.75 / 8.24 |
| κ = 1.5 | 891.3 | 5.55 / 6.08%（0.92） | **4.50 / 0.31%** | 5.22 / 5.81 / 4.93 |
| 光伏为主（风电 ≤ 10 MW，κ = 1.25） | 1393.3 | 1.66 / 1.66%（0.66） | 1.32 / 1.05% | 6.06 / 6.38 / 6.39 |
| 合成年，一年设计（κ = 1.25） | 951.0 | 8.73 / 6.77%（0.27） | **3.66 / 1.46%** | 8.27 / 9.11 / 8.24 |

前四行是 2024–25 条件下的 2 年场景（knob 取自真实 2024–25）；最后一行是 `new 50 scenarios` 中的 50 个单年合成年。"共识设计"指 K 个设计的容量取平均后再检验。

- **单个设计：** 所有配置下，E5 与真实天气类比都没有显著差别。
- **共识设计：** 在 κ = 1.5 和合成年两种情况下，E5 明显更差。平均会消掉随机误差，但消不掉系统偏差，所以偏差在这里才暴露出来。
- **储氢罐：** 五种情况下 E5 都比类比小 5–15%。它是否造成损失，要看真实天气需要多大的罐子。κ = 1.0 时类比配大了，E5 反而更接近最优；κ = 1.5 时 E5 配小，就吃了缺货罚金。

## 3. 哪些统计量驱动设计（单指标扰动）

每项扰动都在 25 个真实类比年上配对比较，表中为均值 [95% CI]。不改任何东西、重复求解一遍的差值恰好为 0，所以表中的差异不是数值噪声。

| 扰动 | 风电为主（κ = 1.25） | 光伏为主 | E5 的实际偏差 |
|---|---|---|---|
| P1 逐日平均风速 std −3.9% | 成本 −8.2 [−8.7, −7.6]；储罐 **−527** [−715, −339] kg；PEM −0.9 MW；真实天气下缺货 **+23** t/年 | 成本 −4.4；储罐 −121 kg；电池 −0.3 MWh | **−3.9%（就是扰动量）** |
| P2 静风小时 −8% | 成本 −4.2；电池 −0.52 MWh；PV −0.7 MW；缺货 +8 t/年；储罐不显著 | 电池 −0.63 MWh，其余不显著 | **−8%（就是扰动量）** |
| P3 日尺度风光相关 −1 sd | 成本 −2.2；储罐 −254 kg | 成本 **−9.5**；储罐 **−626** kg | −0.26 sd（不显著） |
| P4 风速日变幅 +20% | 成本 +0.6；储罐不显著 | 成本 +0.9；储罐不显著 | +20%（+1.2 sd） |
| P5 光伏总量 −3% | 成本 +2.9；储罐 +307 kg；PV 换成风电 | 成本 **+25.0**；PV +2.2 MW；遗憾 **+0.7** 个百分点 | 无偏 |
| P6 逐日光伏 CF std −1 sd（约 −3.6%） | 成本 +0.2，不显著 | 成本 **−14.5**；储罐 **−728** kg | −0.09 sd |

表中成本均为设计自身的成本，单位 USD/t。"sd"指真实年份之间的标准差。

**换算成每 1% 偏差的代价**，可作为容差依据：
- **逐日风速 std**（风电为主）：每偏低 1%，储罐 −135 kg（约为最优罐的 1.6%），成本 −2.1 USD/t，真实天气下缺货 +6 t/年。
- **静风小时**（风电为主）：每少 1%，电池 −0.065 MWh，成本 −0.5 USD/t，缺货 +1 t/年。
- **光伏总量**（光伏为主）：每低 1%，成本 +8.3 USD/t。
- **逐日光伏 std**（光伏为主）：每低 1%，储罐约 −200 kg，成本 −4 USD/t。

**E5 偏差能解释多少：** 以风电为主时，P1 加上按 E5 实际偏差折算的 P3（0.26 × 254 kg），合计约 −590 kg，约为 E5 储氢罐偏差（50 对合成年，−834 kg）的 70%。剩余约 30% 仍找不到对应指标。以光伏为主时，E5 在敏感的三项上都没有偏差，所以与真实天气打平。

**观测筛选**（68 个真实年份，非因果）与扰动结论一致：
- 设计成本的 R² = 0.91，几乎全由平均风速（每 1 sd −45 USD/t）和逐日风速 std（每 1 sd +15.5 USD/t）解释。
- E5 自身最优成本比类比低 14 USD/t，其中约 10 USD/t 来自逐日风速 std 偏低。

## 4. 小时纹理检验

**构造方法：**
1. 风速拆成两部分：日尺度部分 d（24 h 居中滑动平均）和小时残差 r = v − d。
2. X = d（真实类比 k_i）+ r（E5 第 i 年）。
3. 对照 C = d（真实类比 k_i）+ r（另一条独立的真实类比年，knob 序列相同）。
4. 光伏和年均风电 CF 保持不变。X − C 只反映 E5 的小时纹理。

**X − C 复现了 E5 的小时纹理偏差，同时日尺度没有变化：**

| 指标 | E5 − 类比 | X − C |
|---|---|---|
| \|dv\| p99 / p99.9 | −0.04 / −0.18 | −0.05 / −0.23 |
| kurt（dv） | −0.84 | −0.87 |
| wind_max（m/s） | −1.05 | −0.81 |
| win_dvstd_cv | −0.019 | −0.023 |
| sign_keep / acf_absdv_3 | −0.017 / −0.071 | −0.023 / −0.051 |
| 逐日平均风速 std（m/s） | **−0.101** | **+0.004** |
| 静风小时（h/年） | −88 | −29 |

**结果（25 对，κ = 1.25）：**

| 检验 | 指标 | X − C |
|---|---|---|
| 设计 | 成本 | −0.09 [−1.84, +1.66] USD/t |
| | 储氢罐 | −80 [−321, +160] kg |
| | 真实天气下的遗憾 | +0.04 [−0.33, +0.41] 个百分点 |
| | 缺货 | −0.2 [−8.0, +7.6] t/年 |
| | 电池 | **−0.31 [−0.42, −0.19] MWh**（23/25 对变小） |
| 调度（容量固定为真实最优，完全预见 LP） | 运行成本 | +0.7 [−3.5, +5.0] USD/t |
| | 缺货 | +1.7 [−5.8, +9.2] t/年 |
| | 缺电 | −1.0 [−2.1, +0.05] MWh/年 |
| | PEM 待机 | −92 [−172, −11] h/年 |

结论：小时纹理只影响电池这个"小时级缓冲"，而电池在总成本中占比很小。E5 静风小时偏少的部分中，约 1/3 来自小时纹理（短时下探偏少），其余来自日尺度。

## 5. 指标分级（对照 `evaluation-metrics-summary.md`）

### 5.1 重点关注：作为训练目标

| 决策指标 | 你表里最接近的现有指标 | E5 偏差 | 建议容差 |
|---|---|---|---|
| **逐日平均风速 std**（窗口内 24 个日均值的 std） | **风速方差**（第 2 节"边缘矩"）。它与逐日 std 在真实年份间的秩相关 ρ = 0.98，E5 −4.0%。其次是 v ACF 24（ρ = 0.67，E5 −8.7%）。**不要用 PSD 2–7 d 的占比**：E5 在这一项上 +7.8%，方向相反，因为占比被 3–12 h 多出的功率扭曲了，与逐日 std 的 ρ = −0.08。 | −3.9%（−0.56 sd，50/50 对 Wilcoxon p < 0.001） | \|偏差\| ≤ 1%（储罐误差 ≤ 135 kg） |
| **静风小时数**（风电 CF < 0.05，即 v < 4.47 m/s） | **lull 小时占比**（v < 3.53，ρ = 0.92，E5 −13%）。其次是 v p25（ρ = −0.94，E5 +1.9%）和 v p5（ρ = −0.75，E5 +8.1%）。 | −8.0%（−0.90 sd） | \|偏差\| ≤ 2% |

建议直接计算这两个决策指标（代码见附录 A）。现有的近似指标只适合调试时快速查看。

### 5.2 守住：决策敏感，E5 目前无偏，只要求不变差

| 指标 | 现有对应 | 为什么要守 | E5 现状 |
|---|---|---|---|
| 平均风速 / knob 跟踪 | 平均风速、knob tracking | 设计成本对它最敏感（每 1 sd −45 USD/t） | 合成年 24 天窗口均值减 knob：平均 +0.01 m/s，RMS 0.74 m/s |
| 光伏总量 | GHI mean bias | 光伏为主时，−3% 就使成本 +25 USD/t、遗憾 +0.7 个百分点 | 与类比无偏（相对真实 2024–25 低 3%，但类比年同样低，这是 2024–25 本身偏晴） |
| **日尺度风光相关**（风电日均 CF 与光伏日均 CF 的 Pearson r） | 只有逐小时的 wind–GHI r（ρ = 0.87，可作近似） | 光伏为主时，−1 sd 使储罐 −626 kg | −0.26 sd，不显著 |
| **逐日光伏 CF std** | 最接近的是日累计 GHI 的 p10–p90，建议直接算 std | 光伏为主时，−1 sd 使储罐 −728 kg | −0.09 sd |
| 多日低风段（longest lull、lull p90） | spell 中的 lull 指标 | 观测筛选中与储罐相关，未做扰动 | longest lull −2.5%，不显著 |

### 5.3 维持即可：保持现状，不必再推

- **你改模型时常看的指标（除 wind_max）：** \|dv\| p50、p75、p90、p99、p99.9，kurt_pooled，win_dvstd_cv。E5 在合成年上的偏差依次为 \|dv\| p50 至 p90 都在 −1% 以内、p99 −2.2%、p99.9 −6.5%，kurt −13%（5.57 vs 6.40），win_dvstd_cv −13%（0.127 vs 0.146）。这些偏差都包含在第 4 节换进去的纹理里，对设计和调度都没有显著影响。
- **其余小时尺度的指标：** sign_keep、acf_absdv_3/6、dv ACF lag 1–6、rough、big_reversal、big jumps、ramp6、e 的分位数和 ACF、egen_cv、calm/active spell（以 e 定义）、same-sign ramp spell、PSD < 3 h 和 3–12 h、burst/edge、seam check。
- **整体分布和多样性：** FID、P/R、Density/Coverage、coverage/PIT、bin slope、spread ratio。这些没有做下游检验，作为通用健康检查保留。
- **有效性检查**（memorization、leak、position profile、noise symptom）：不是性能指标，照常保留。

注意：调度检验用的是完全预见 LP。如果下游换成 RL 或滚动时域调度，ramp 的持续性（sign_keep、dv lag 2/3）可能影响策略学习，所以这些指标是"维持"而不是"删掉"。换下游后，用第 4 节的方法重测一遍即可。

### 5.4 对这个下游可以不看

| 指标 | 原因 |
|---|---|
| wind_max、v p99 / p99.9、年最大风速、high wind 最长时段 | 12–25 m/s 之间风电满发，出力不随风速变化。除非生成值超过 25 m/s 触发切出（E5 年最大约 21 m/s），否则 MILP 看不到。 |
| 风速日变幅、峰值钟点（合成年 diurnal amplitude 0.83 vs 0.46–0.50） | P4 扰动 +20% 后成本变化 ≤ 0.9 USD/t，储罐不显著。 |
| 所有 PSD 份额类指标 | 份额会被其他频带的变化带偏（见 5.1）。需要频域信息时改用绝对功率。 |

### 5.5 判定方式

- **5.1 和 5.2 的指标：** 用相同的 `knobs_per_window.csv` 生成合成年，与同 knob 的真实类比年配对，报偏差 ± 95% CI，并按上面的容差判断。真实逐年 p10–p90 区间太宽，反映的是年际差异，不是模型误差。E5 的逐日风速 std 只有 50% 的年份落在区间内（无偏时应约为 80%），但均值落在区间内，按现行规则算达标。
- **5.3 的指标：** 继续沿用现在的真实范围规则。只要不明显变差，就不作为修改方向。

## 6. 训练上的建议

按批次匹配窗口内的逐日方差，做法类似 module 1，只在低噪声步启用。下式中 v 为配对的真实窗口，v̂ 为模型输出的去噪窗口：

```
d̂_b,j = mean( v̂_b, 第 j 天的 24 h ),   j = 1…24（576 h 窗口共 24 天）
L_day  = ( mean_b std_j(d̂_b,j) − mean_b std_j(d_b,j) )²
L_calm = ( mean_b,t σ((4.47 − v̂_b,t)/τ) − mean_b,t 1[v_b,t < 4.47] )²     （τ ≈ 0.3 m/s，用软计数代替硬阈值）
```

每个窗口只有 24 个日均值，单个样本的 std 噪声很大。所以 L_day 在批次上取平均后再比较，相当于匹配分布，而不是逐样本重建。

## 7. 尚未覆盖、需要注意的地方

- E5 合成年的 knob 来自 2024–25，而真实检验也用 2024–25，所以不是完全样本外的检验。E5 的 test 集是 2022 年以后，类比年取自 2005–2023（不含 2021）的历史数据。
- 只测了一个站点、一个下游模型，罚金 5000 USD/t 的取值没有做敏感性分析。
- E5 储氢罐偏差中约 30% 没有找到对应指标。
- 小时纹理替换本身会让逐日 std 和静风小时比原类比年略低。X 和 C 共有这一误差，相减时抵消，但两者的基准都偏离了原类比年一点。
- 其他模型版本（A、E6、F2、TKW）还没有做下游评估。需要用同一份 knob 文件生成的合成年，每个模型 25 年就够。

## 附录 A：四个新指标的计算

输入为逐小时序列：v 是风速（m/s），cf_pv = clip(0.86 × GHI / 1000, 0, 1)，cf_wind 由三次方功率曲线换算（切入 1.5 m/s、额定 12 m/s、切出 25 m/s）。

```python
import numpy as np

V_CALM = (1.5**3 + 0.05 * (12.0**3 - 1.5**3)) ** (1 / 3)  # 4.47 m/s，风电 CF = 0.05

def wind_cf(v):                                  # 与 run_ptm_examples.wind_power_cf 相同
    cf = np.clip((v**3 - 1.5**3) / (12.0**3 - 1.5**3), 0.0, 1.0)
    return np.where(v > 25.0, 0.0, cf)

def daily(x):
    return x[: len(x) // 24 * 24].reshape(-1, 24).mean(1)

def std_daily_mean_wind(v, window=576):          # 窗口内逐日均值的 std，再对窗口取平均
    return np.mean([daily(v[s:s + window]).std() for s in range(0, len(v) - window + 1, window)])

def calm_hours_per_year(v):
    return (v < V_CALM).sum() * 8760 / len(v)

def daily_wind_pv_corr(v, cf_pv):
    return np.corrcoef(daily(wind_cf(v)), daily(cf_pv))[0, 1]

def std_daily_pv(cf_pv):
    return daily(cf_pv).std()
```

第 3 节用的是整年 365 个日均值的 std。按 576 h 窗口计算时，E5 的偏差同样是 −3.9%（2.34 vs 2.44 m/s，Wilcoxon p = 2.5e-4），所以训练中按窗口计算即可。
